# SEO Keyword Manager

A simple and user-friendly SEO keyword management tool for organizing, tracking, and managing keywords in one place.

## 📌 Features

* Add and manage SEO keywords
* Organize keywords into projects
* Search and filter keywords
* Search intent management
* Keyword difficulty tracking
* Search volume tracking
* CPC tracking
* Competition tracking
* Content type management
* Keyword clustering
* Target URL management
* Ranking tracking
* Keyword priority management
* Notes for individual keywords
* Bulk keyword adding
* Duplicate keywords
* CSV export
* Print / PDF
* Dark mode
* Customizable keyword lists

## 💡 How to Use

1. Open the tool using the live demo link.
2. Create or select a project.
3. Add your SEO keywords.
4. Add information such as search volume, difficulty, intent, competition, and priority.
5. Use the search and filters to organize your keywords.
6. Export your keyword data as CSV when needed.

## 🔒 Data & Privacy

The tool stores keyword data locally in the user's browser.

No account or login is required.

Your keyword data is separate from other users' browser data.

## 🛠️ Technology

This project is built using:

* HTML
* CSS
* JavaScript
* Browser Local Storage
